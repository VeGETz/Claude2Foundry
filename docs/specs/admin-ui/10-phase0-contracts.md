### SSE event schema — `GET /api/admin/events`

Server emits one SSE event per phase per request, plus replay events on connect.

Event types (`event:` field):

| `event:` | When emitted | `data:` payload |
|---|---|---|
| `replay.snapshot` | First frame on every connection; carries the current ring buffer | `{ "records": [<RequestRecord-summary>...] }` |
| `request.received` | Inbound request parsed | `{ "id": string, "ts": iso8601, "originalModel": string, "stream": bool, "bodyPreview": object?, "headers": object }` |
| `request.translated` | OpenAI body built | `{ "id": string, "resolvedModel": string, "openaiBody": object? (only if capture mode = full or body fits in preview budget) }` |
| `foundry.request.sent` | Outbound HTTP POST issued | `{ "id": string, "ts": iso8601 }` |
| `foundry.chunk` | Streaming chunk received from Foundry | `{ "id": string, "seq": int, "deltaText": string?, "deltaToolCall": object?, "reasoningDelta": string? }` |
| `foundry.complete` | Upstream stream/non-stream done | `{ "id": string, "usage": { "input": int, "output": int }, "finishReason": string }` |
| `response.sent` | Final byte sent to Claude Code | `{ "id": string, "elapsedMs": int, "anthropicAssembled": object? }` |
| `error` | Any phase failed | `{ "id": string, "phase": string, "origin": "Adapter" | "Foundry", "message": string }` |

The `id` is the existing `x-c2f-request-id` correlation id; UI uses it as the table row key. SSE `id:` field is set to a monotonic sequence number for client `Last-Event-ID` reconnect.

**Backpressure:** server keeps a per-client bounded outbound queue. On overflow, the server drops the oldest **non-terminal** events (`foundry.chunk`, intermediate phases) but never drops `error` / `*.complete` / `response.sent`. The client sees a gap in `foundry.chunk.seq` and renders `[N chunks dropped]`.

### JSON Schema for `ProxyConfig`

Served at `GET /api/admin/config/schema`. Draft 2020-12. Includes:

- Field types, required flags, enums (`ReasoningPolicy: ["none","passthrough","effort"]`, `TokenizerSource: ["TiktokenCl100k","TiktokenO200k","HuggingFace"]`).
- Semantic constraints expressible in schema: `BackendUrl` regex `^https?://.*/openai/v1/?$`; `Timeouts.OutboundTotalSeconds` minimum 1; `Timeouts.StreamIdleSeconds` minimum 1.
- `Monitor` section (new, added by this feature): `CaptureMode` enum `["hybrid","full"]`, `LogMaxBytes` integer ≥ 1 048 576, `LogRetentionDays` integer ≥ 0.

A hand-written JSON Schema document lives in `docs/specs/admin-ui/contracts/json-schema.md` for traceability; the server is allowed to generate the same shape from C# types in phase 1.

### Data dir resolution

`Config/DataDirResolver.ResolveDataDir(IHostEnvironment env)`:

1. If env var `C2F_DATA_DIR` set and non-empty → use that path. Create the directory if missing.
2. Else, on each OS:
   - Windows: `%LOCALAPPDATA%\Claude2Foundry\` (`Environment.GetFolderPath(SpecialFolder.LocalApplicationData)`).
   - Linux: `$XDG_DATA_HOME/claude2foundry/` if set, else `~/.local/share/claude2foundry/`.
   - macOS: `~/Library/Application Support/Claude2Foundry/`.
3. If creation of the OS user-data dir fails (read-only home, etc.) → fall back to `Environment.CurrentDirectory`. Log a `Warning` once at startup naming the resolved path.

Subpaths used elsewhere:

- `<datadir>/appsettings.local.json`
- `<datadir>/logs/requests-YYYY-MM-DD.jsonl`

### CORS + CSRF middleware

For `/api/admin/*` only:

- Reject all CORS preflight (`OPTIONS`) requests whose `Origin` is not `http://127.0.0.1:8787` (the embedded Console) or `http://127.0.0.1:5173` (Vite dev server, only when an env var `C2F_DEV=1` is set — disable in production builds).
- On every response, set `Access-Control-Allow-Origin: null` (deny cross-origin reads).
- On every mutating request (`POST`/`PUT`/`DELETE`/`PATCH`), require header `X-C2F-Admin: 1`. Missing → `400 missing X-C2F-Admin`. The value `1` is exact-match; anything else also rejects.
